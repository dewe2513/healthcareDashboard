# Healthcare Dashboard

A Power BI dashboard analyzing patient data and visualizing disease symptoms, demographics, and health outcomes.

## Overview

This project is a healthcare analytics dashboard built with Power BI. It analyzes patient data from the `data/` folder to visualize disease patterns, symptoms, and patient demographics.

## Installation Instructions

**Prerequisites:**
- [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free download)

**Setup:**
1. Clone or download this repository
2. Install Power BI Desktop if you haven't already

## Usage Instructions

Use this dashboard to analyze patient data, disease patterns, and health outcomes.

**Preferred Method: Open with Power BI Desktop**
1. Open Power BI Desktop
2. Open the file `CISC489_FINALPROJECT_SAMDEWEY.pbix`
3. Interact with the visualizations and filters to explore the data

**Alternative: View Webpage**
- Open `index.html` in a web browser
- Note: This only displays a static image of the dashboard, not the interactive version

## Project Contents

- `CISC489_FINALPROJECT_SAMDEWEY.pbix` - Power BI dashboard file
- `data/` - Contains the source data used to create the dashboard (data sourced from kaggle.com)
- `index.html` - Simple webpage displaying a screenshot of the dashboard
- `image/Dashboard.png` - Dashboard screenshot
